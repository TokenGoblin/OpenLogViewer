- **MaxxECU command 0x2F erases the ECU's flash** (from the w1-ms-maxx review). The C# never guarded it: every caller just passes a fixed command (`MaxxUsbSource` 0x16/0x13/0x12/0x10, `MaxxCan` 0x38, `MaxxTune` 0x05/0x37). The Rust now refuses it in `olv_protocol::ms::maxx_usb_protocol::request`. Keep it that way, and do not add a path around it. The other write protection is `MaxxTune.WriteCeiling = 0xF2E7` (`MaxxTune.cs:218`, enforced near line 275). Port it exactly, with a test that a write past it is refused.
