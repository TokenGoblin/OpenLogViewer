SUSTAINED RATE, eight consecutive reads:
  131, 137, 143, 143, 148, 153, 154, 162 ms   -> ~146 ms mean
  ~6.8 bytes per second

Which is slow, and mostly does not matter. The parameters worth having over
SSM -- knock correction, fine knock learn, IAM, A/F learning -- are learned
values that move over seconds and minutes, not transients. Eight of them is
about 1.2 s a round, near enough 0.85 Hz. For catching a misfire it is
useless; for watching what the ECU has learned over a drive it is ample.

ONE WRONG, AND IT WAS THE INTERESTING ONE:

  0x000022 "Knock Correction" answered raw 0xFF, which decodes to +63.5 deg
  and is impossible. 0xFF is the not-supported sentinel. That address is
  base-set only; on an FB20 knock lives in a calibration-specific RAM
  address -- the map has entries like 0x021975 and 0x801308 for other
  parameters in that space. Removed from the parameter file rather than
  left to show alarming nonsense. Still to find.
